# Telegram Todo Bot

Простой Telegram-бот для создания и учёта задач. Бот написан на Python с использованием aiogram 3 и SQLite.

## Возможности

- Добавление задач с текстом и категорией.
- Просмотр списка задач с их ID, категориями и статусами.
- Отметка задачи как выполненной.
- Выгрузка списка задач в CSV.
- Постоянная клавиатура и команды в системном меню Telegram.
- Автоматическое создание базы данных и миграция старой таблицы задач: при добавлении полей статуса и категории существующие задачи сохраняются.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота, созданного через [@BotFather](https://t.me/BotFather).

## Установка и запуск

1. Склонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/roland-nimoj/telegram-todo-bot.git
   cd telegram-todo-bot
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

   В Windows активируйте окружение командой:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе `.env.example` и укажите токен:

   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

   Файл `.env` содержит секрет и не должен попадать в Git. Также токен можно передать через переменную окружения `BOT_TOKEN`.

5. Запустите бота:

   ```bash
   python main.py
   ```

При запуске бот проверяет наличие токена, создаёт или обновляет таблицу базы данных и начинает получать сообщения. Для остановки нажмите `Ctrl+C`.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Показать приветствие и меню |
| `/add` | Начать добавление задачи |
| `/list` | Показать задачи |
| `/list_csv` | Получить список задач в CSV-файле |
| `/done` | Выбрать задачу для отметки выполненной |
| `/done 1` | Отметить задачу с ID `1` выполненной |
| `/cancel` | Отменить текущее добавление или выбор задачи |

После `/add` бот попросит ввести текст задачи, а затем категорию. Можно выбрать предложенную категорию (`Работа`, `Дом`, `Учеба`) или написать свою. Новая задача получает статус «В работе».

После `/done` без ID бот попросит ввести номер задачи. ID можно посмотреть командой `/list`. Неизвестный ID не изменяет данные.

## Хранение данных

Задачи хранятся в SQLite-файле `tasks.db` в текущем рабочем каталоге. В таблице сохраняются ID, текст задачи, имя пользователя, дата создания, статус и категория. Начальный статус — «В работе», статус выполненной задачи — «Выполнено».

Список задач и CSV-выгрузка включают задачи из общей базы бота, а не только задачи пользователя, который вызвал команду. CSV содержит столбцы ID, задача, пользователь, дата, статус и категория; значения разделяются точкой с запятой.

Незавершённые шаги диалога хранятся в памяти процесса. После перезапуска бота такой диалог нужно начать заново; уже сохранённые задачи остаются в `tasks.db`.

## Файлы проекта

- `main.py` — точка входа, обработчики команд, логика задач и работа с базой.
- `requirements.txt` — зависимости Python.
- `.env.example` — шаблон переменной окружения для токена бота.
